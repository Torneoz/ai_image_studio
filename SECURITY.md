# Security policy

## Supported versions

AI Image Studio is pre-release software. Security fixes are applied to the
latest development branch until a stable release policy is published.

## Reporting a vulnerability

For a Drupal.org release covered by the Drupal Security Team, use the private
security-reporting process linked from the project page.

Before Drupal.org security coverage is available, report vulnerabilities
privately to the repository maintainers through GitHub's private vulnerability
reporting feature. Do not disclose suspected vulnerabilities in a public issue.
